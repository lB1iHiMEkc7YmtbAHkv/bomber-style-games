# ボンバー風ゲーム

炎・氷・歯車・闇・迷宮・盤・賽・時。8人の王がそれぞれ違うルールで待っている、ブラウザで遊べるボンバー風の対戦ゲーム集です。
木箱を壊してアイテムを集め、CPU相手に最後の1体まで生き残りましょう（リバーシ風は石の数で勝負、すごろく風はターン制で上がりをめざす）。

各ゲームは外部ライブラリ不要の単体HTMLファイルです（Webフォントのみ Google Fonts から読み込みます）。

## 遊び方

`index.html` をブラウザで開き、挑戦したい王を選びます。どの王から挑んでも大丈夫です。
ルールが一番素直なのはランタン、いちばん手ごわいのはおばけです。

## 各ゲームの紹介

### ランタン風（炎の王）
ランタン族のポッコが主役の王道ルール。木箱を壊してアイテムを集め、最後の1体まで生き残ります。

### つらら風（氷の王）
つらら族のフブキを操作します。水色の氷の床に乗ると、壁やボムにぶつかるまで止まれません。爆風が通った床もしばらく凍るので、逃げたつもりが滑って戻ることもあります。

### からくり風（歯車の王）
からくり族のゼンマを操作します。床のコンベアがキャラもボムも運んでいき、向きは12秒ごとに全部反転します。丸い回転床は2秒ごとに向きが変わります。ボムを流して遠くの相手を狙いましょう。

### おばけ風（闇の王）
よる族のヨミを操作します。ステージは真っ暗で、見えるのはちょうちんの明かりと爆発で一瞬照らされた場所だけ。導火線の音（スタート後に鳴ります）を頼りに、見えないボムと相手を避けます。

### 迷宮風（迷宮の王）
ぼうけん者のカイを操作します。初期の3Dダンジョンゲームのような線画の迷宮を、一人称視点で一歩ずつ進みます。見えるのは目の前だけなので、右のマッピング（一度見たマスが記録される方眼紙）と、左右に振り分けられる爆発音を頼りに戦います。足元が爆風の範囲に入ると画面が赤く光り、ボムの方向（まえ・うしろ・みぎ・ひだり）と残り時間が表示されます。やられた後はCPUの視界に切り替わり、`←` `→` で観戦するCPUを切り替えられます。

| 操作 | キー |
| --- | --- |
| 前進・後退 | `↑` `↓` / `W` `S` |
| 向きを変える（90度） | `←` `→` / `A` `D` |
| 横歩き | `Q` `E` |

### リバーシ風（盤の王）
黒石のクロ（あなた）と、白のシロ・赤のアカ・青のアオのCPU（1〜3体、ヘッダーで選択）が、ほかの作品と同じくリアルタイムで盤を取り合います。ボムを置けるのは緑のマスとほかの人の色のマスだけで、自分の色のマスには置けません。

ボムがリバーシの石の代わりで、爆発するとそのマスと爆風が通ったマスが自分の色に変わります（木箱を壊したマスは緑のまま残ります）。さらに爆発したマスから8方向を見て、自分以外の色を自分の色ではさんでいたら、はさまれた列がまるごと裏返って緑白の爆風になります。盤の中央の2×2には最初から石が置いてあります（1対1ならリバーシと同じ黒白2個ずつ、3人以上なら1人1個）。爆風に当たってもキャラは倒れません。時間切れで終わりで、自分の色の数がいちばん多い人の勝ちです。

- 操作は共通と同じです（`←` `↑` `↓` `→` / `WASD` で移動、`Space` / `Z` でボム）。
- アイテム「ななめ爆風」を取ると、ふつうの爆風がななめ4方向にも伸びます。

### すごろく風（賽の王）
さいころ族のコロ（あなた）と、ゴロ（上がり重視）・ピン（こうげき好き）・ゾロ（バランス型）のCPU（1〜3体）が、ターン制で6面のサイコロをふって進みます。時間切れはありません。

- 目の数だけ1マスずつ進みます。1本道は自動で進み、分かれ道では十字キーで進む方向を選びます（同じ手番で同じマスは2度通れない）。白く光るマスがその先で止まれる場所です。目の数だけ進めないときは、進めるところまで。
- 盤の真ん中の「上がり」にぴったり止まればクリア。ボムで相手を全員倒してもクリアです。
- 四隅の陣は外周の道でつながっていて、各辺の中央と陣から伸びる階段道が内側の輪を経て上がりへ続きます。相手の陣に乗りこんでボムを置くのもあり。
- 進んだあと、止まったマスにボムを置けます。ボムの数字は置いた人の手番が来るたびに1へり、0で爆発（ほかの人は2回、置いた人は1回逃げられる）。爆風は道の上をまっすぐ伸び、木箱で止まり、ほかのボムを誘爆させます。爆発しそうなマスは赤く表示されます。
- 木箱とボムは通れません。ほかのキャラは通りぬけられますが、同じマスには止まれません。
- ★のマスに止まると、もう1回サイコロをふれます。
- 盤の形は固定で、木箱・アイテム・★の位置がシードで変わります（4つの陣が同じ条件になるよう、90度ずつ回した同じ配置）。
- アイテム「ちょうせい」はためておけて、ふった目を1つ増やすか減らせます。

| 操作 | キー |
| --- | --- |
| サイコロをふる・ボムを置かずに終わる | `Space` / `Enter` |
| 分かれ道で進む方向を選ぶ | `←` `↑` `↓` `→` / `WASD`（画面下の矢印ボタンや、矢印の出ているマスのクリック・タップでも選べる） |
| ボムを置く | `Z` |
| ちょうせい −1 / +1 | `Q` / `E` |

### 砂時計風（時の王）
とき族のトキを操作します。ルールはランタン風と同じ王道ルールで、それに加えて頭の砂時計で2つの時の力が使えます。CPUも同じ力を使ってきます。

- **3秒前に戻る**（`X`）：3秒前にいたマスへ一瞬で戻ります。足元にうすい青の残像と点線の足あとが出ていて、残像の場所が戻る先です。戻れるのはキャラの位置だけで、ボムや爆風の時間は戻りません。
- **3秒後へ進む**（`C`）：…というのは名前だけで、正体はマップのどこかへのワープです。行き先は選べません（今いる場所から3マス以上離れた、そのとき燃えていない空きマスのどこか）。
- どちらも一度使うと、砂が落ちきるまで使えません（戻るは7秒、進むは10秒）。頭の砂時計の上の砂が、戻るの残り時間です。
- アイテム「砂時計」を取ると、待ち時間が2割ずつ短くなります（最短で元の4割）。

| 操作 | キー |
| --- | --- |
| 3秒前に戻る | `X`（スマホは「戻る」ボタン） |
| 3秒後へ進む（ワープ） | `C`（スマホは「進む」ボタン） |

## 操作方法（共通）

| 操作 | キー |
| --- | --- |
| 移動 | `←` `↑` `↓` `→` / `W` `A` `S` `D` |
| ボム設置 | `Space` / `Z` |
| 同じマップでやり直し | `R` |
| スタート | スタート画面で `Enter` / `Space` でも可 |

- からくり風のみ、リモコンボム所持時に `X` で起爆できます。
- 砂時計風のみ、`X` で3秒前に戻り、`C` でワープします。
- 迷宮風のみ、`←` `→` は「向きを変える」になります（迷宮風の紹介にある表を参照）。
- すごろく風はターン制のため操作が異なります（すごろく風の紹介にある表を参照）。
- やられた後もCPU同士の対戦を観戦できます（リバーシ風はキャラが倒れず、石の数で決着）。
- スマホでは画面下の十字キーとボムボタンで操作できます。
- スタート画面で対戦するCPUの数（1〜3体、初期値3体）を選べます。

## アイテム

木箱を壊すと出現します。

| アイテム | 効果 |
| --- | --- |
| 火力アップ | 爆風が1マス伸びる |
| ボム追加 | 同時に置けるボムが+1 |
| スピード | 歩く速さが上がる |
| キック | ボムに向かって歩くと蹴り飛ばす |
| シールド | 爆風を1回だけ防ぐ（リバーシ風にはなし） |
| ちょうせい | ふった目を1つ増やすか減らせる（すごろく風） |
| 貫通ボム | 爆風が木箱を貫く |
| リモコンボム | 好きな時に爆発させる（からくり風） |
| ななめ爆風 | 爆風がななめ4方向にも伸びる（リバーシ風） |
| 砂時計 | 戻る・進むの待ち時間が短くなる（砂時計風） |

※ アイテムの種類はゲームごとに異なる場合があります。

## 起動方法

ビルド不要です。ファイルをブラウザで直接開くか、簡易サーバーで配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
